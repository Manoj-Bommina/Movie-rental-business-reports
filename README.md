# Movie Rental Business Reports

## Project Overview
This project uses PostgreSQL to analyze a movie rental business database and generate reports that help answer business questions about movies, customers, rentals, and payments.

The goal is to practice SQL by building practical business reports using a sample DVD Rental database.

## Tools Used
- PostgreSQL
- DBeaver
- SQL
- GitHub

## Business Questions
This project answers the following questions:

1. How many films are available in the database?
2. How many films belong to each category?
3. Which customers have paid the most in total rental payments?
4. Which dates had the most rental transactions?
5. Which films are rented most often?
6. Which film categories generate the most rental payment revenue?

## SQL Concepts Used
- SELECT statements
- Aggregate functions: COUNT() and SUM()
- JOIN operations
- GROUP BY
- ORDER BY
- LIMIT
- Date functions

## Project Files
- `01_movie_rental_reports.sql` — Contains SQL queries for database checks, film counts, category reports, customer payment analysis, rental activity, popular films, and category revenue.

## Key Learnings
- Explored a relational database and its tables.
- Connected related tables using JOIN operations.
- Summarized business data using aggregate functions.
- Ranked results to identify top customers and popular movies.
- Used SQL to answer practical business questions.

## How to Run
1. Set up PostgreSQL and DBeaver.
2. Restore or connect to a compatible DVD Rental sample database.
3. Open `01_movie_rental_reports.sql` in DBeaver.
4. Execute the queries and review the results.
